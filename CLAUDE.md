# maospix-kde

Distro propia de Marcos Olmedo (maospytek, Itauguá, Paraguay), parte de la familia maospix.
Base: Arch Linux + KDE Plasma. Estilo: tipo Xero Linux / Garuda (todo preinstalado y tematizado).
Se construye con archiso, con instalador gráfico (Calamares).

## Reglas
- Todos los proyectos nuevos se llaman maospix-* (este es maospix-kde).
- Marcos habla español y prefiere explicaciones breves y prácticas.
- Avanzar de a un paso: esperar que pruebe el comando y confirme el resultado.
- Al indicar editar un archivo, dar el comando completo (ej. nano ruta/archivo).

## Proyectos previos (referencia)
- maospix-bspwm: Fedora + bspwm, Polybar, Rofi, Eww (github.com/maospy/maospix-bspwm)
- maospy-hypr: Arch + Hyprland con instalador de un solo comando (github.com/maospy/maospy-hypr)

## Entorno
- Esta máquina es Arch minimal, solo banco de trabajo para construir la ISO. Se accede por SSH desde Windows.
- Usuario: maospy. Carpeta del proyecto: ~/maospix-kde
